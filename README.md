# The Ultimate React Course

This repository contains all the projects, exercises, and notes from the **Complete React Course**. The course covers modern React development, best practices, and building real-world applications with React and related technologies.


## Course Content

### 1. React Fundamentals
- Components, JSX, and Props
- Events and Forms
- State Management
- Component Lifecycle
- Thinking in React

### 2. State Management
- Local vs Global State
- UI vs Remote State
- Where to Place State
- Lifting State Up
- Context API
- Redux & Redux Toolkit
- React Query

### 3. Component Design
- Building Reusable Components
- Composable Component Architecture
- Children Prop and Component API
- Advanced Patterns (HOCs, Render Props, Compound Components)

### 4. Effects and Hooks
- Deep Dive into useEffect
- Rules of Hooks
- Custom Hooks
- useRef, useReducer, and More
- Synchronization vs Lifecycle

### 5. Performance Optimization
- Preventing Wasted Renders
- Memoization with memo, useMemo, useCallback
- Code Splitting and React.Suspense
- Optimizing Context API

### 6. Routing and SPAs
- React Router (including v6.4+)
- URL Parameters and Query Strings
- Data Loading Strategies
- Building Single-Page Applications

### 7. Styling in React
- Tailwind CSS
- CSS Modules
- Styled Components (CSS-in-JS)

### 8. Next.js
- App Router Architecture
- React Server Components
- Server Actions
- Data Loading and Caching
- Static vs Dynamic Rendering
- Image and Font Optimization
- Authentication with NextAuth

### 9. Real-world Features
- Authentication and Authorization
- Data Sorting, Filtering, and Pagination
- Dark Mode Implementation
- Charts and Dashboards
- Form Handling with React Hook Form

### 10. Behind the Scenes
- Virtual DOM and Reconciliation
- Fiber Tree Architecture
- The Key Prop
- Event System
- State Batching

## Projects

1. **React Fundamentals App** – A starter project to learn components, props, and state.

2. **usePopcorn** – A movie tracking application to master state management and effects.

3. **React Quiz** – An interactive quiz app exploring advanced state management with useReducer.

4. **Travel List** – A packing list application for practicing component composition and state.

5. **Eat-n-Split** – A bill splitting app focusing on forms and state management.

6. **React Router SPA** – A single-page application showcasing routing and data loading.

7. **Redux E-Commerce** – An online store using Redux Toolkit for global state management.

8. **React Compound Components** – Building a UI library with advanced component patterns.

9. **The Wild Oasis** – A full-featured hotel management system with Supabase backend, authentication, dashboard, and bookings management.

10. **Fast React Pizza Co.** – A pizza delivery application with cart, checkout, and order tracking functionality.

11. **Next.js Application** – A modern web app built with Next.js, Server Components, and Server Actions.
